# Automated Interior Design System
An industry project that automates interior design optimization using Unity and C# scripting. The system transforms research-based mathematical models into actionable design solutions.

# Features
- Automated Design Generation: Converts mathematical expressions from research into functional code.
- Optimization with Genetic Algorithms: Implements multidimensional optimization to reduce design iteration time by 40%.
- Collaboration & Insights: Bridges technical concepts with stakeholder requirements for practical implementation.

# Technology Stack
- Language: C#
- Platform: Unity Engine
- Algorithm: Genetic Algorithm (GA) for optimization

# Outcome
- Significantly accelerated design iterations for industry clients.
- Streamlined the integration of research concepts into industry workflows.
